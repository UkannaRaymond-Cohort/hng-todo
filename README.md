# Taskflow

An advanced, local-first todo application with a dense productivity UI.

## Features
- Inbox, Today, Upcoming, and Completed views
- Quick task creation
- Search with `Cmd/Ctrl + K`
- Keyboard shortcut `N` for new task
- Status and priority management
- Due dates and times
- Projects and tags
- Subtasks
- Recurring-task metadata
- Task duplication and deletion
- Persistent local state
- Responsive detail panel/mobile layout
- `AGENT.md` for AI-assisted development

## Run

```bash
pnpm install
pnpm dev
```

Then open `http://localhost:3000`.
